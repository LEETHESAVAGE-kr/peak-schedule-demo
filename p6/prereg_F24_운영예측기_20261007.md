# 사전등록 — F24 시나리오 운전표 (운영예측기 극복리서치 PRD §6, 결정문서_20261007.md, 2026-10-07)

이 파일은 스크립트(`f24_scenario_schedule.py`) 실행 전에 쓰였다. 스크립트는 이 파일의 SHA256이 코드에 박힌 값과 같을 때만 돈다.
결과를 본 뒤 아래 어느 것도 바꾸지 않는다. 코드 오류로 다시 돌리면 `research/F24_실행기록.md`에 횟수와 고친 내용을 적는다.
사용자 결정(10/7): 후보 2개(H2 최악형 → H1′ 기대형)를 이 사전등록 하나로 함께 겨룬다. 이것은 F23(미집행)을 실행 전에 후보 하나(W2)를 더한 판이며, 같은 4개월에서의 시도 횟수는 F23과 같다. 이 판이 부분·실패여도 후속 변형은 만들지 않는다.

## 1. 정책(공통)

- 운전표 v2 B와 같은 조건: 이동 창 ±16슬롯(±4h), 유입 상한 cap = 20kW, TOU 2단, 다음 날 이월 없음(carry=False), 에너지 보존, 생산 손실 0.
- 결정 변수는 이동 **비율** x[t,w] ≥ 0(|t−w| ≤ 16, Σ_w x[t,w] = 1). 모든 시나리오에서 s·y_j[t] ≤ 1e-9인 출발 슬롯은 x[t,t] = 1로 고정한다.
- 시나리오 j(과거 실측 하루 y_j, 가중 π_j)마다
  - 피크: P_j ≥ (1−s)·y_j[w] + Σ_t s·y_j[t]·x[t,w] (모든 w)
  - 상한: Σ_{t≠w} s·y_j[t]·x[t,w] ≤ cap (모든 w)
- 1단 목적: **R(최악형) = min max_j P_j**, **W(기대형) = min Σ_j π_j·P_j**.
- 2단: 1단 값 v*를 묶고(R: 모든 j에서 P_j ≤ v* + 1e-6·max(1, v*), W: Σ π_j P_j ≤ v* + 1e-6·max(1, v*)) Σ_j π_j Σ_{t≠w} 단가[w]·s·y_j[t]·x[t,w] + 1e-3·Σ_j π_j Σ_{t≠w} s·y_j[t]·x[t,w] 최소화(plan2와 같은 구조, 단가 = `f14_schedule_v2.price`, 선택Ⅰ).
- 실현: out_d = (1−s)·y_d + (s·y_d) @ x (실측에 비율 적용, 기존 `run_variant`와 같은 식).
- CBC(pulp 기본), msg=0.

## 2. 시나리오 집합

- **A(d)** = 같은 요일 d−7·−14·−21·−28일 중 완전한 날(96슬롯)인 날의 실측(`f11_dayahead.naive`가 쓰는 날과 같다). 부하 벡터가 같은 날(복제군)은 가장 이른 날 하나만.
- **B(d)** = F21 C1의 kNN 4일(`f21_decision_forecaster.knn`의 후보 규칙·특징·표준화·거리·k=4 그대로 — d−2 이전에 끝난 같은 요일 유형의 날, 복제군 하나).
- A∪B는 날짜 기준 합집합 후 부하 벡터 기준으로 다시 중복 제거. 가중 π는 합집합 위의 균등.
- 시나리오가 2일 미만이면 그날은 C0(직전 4주 중앙값 한 줄, plan2)로 대체하고 일수를 적는다. 0일이면 무계획.

## 3. 후보 (선택 대상 4개 — 늘리지 않는다)

| ID | 시나리오 | 위험 척도 | 의미 |
|---|---|---|---|
| C0 | 직전 4주 중앙값 한 줄(현행, `run_variant`) | — | 기준선. `build/table_f21_rolling.csv`의 C0 행과 같아야 한다 |
| R1 | A | 최악 | 강건 최적화만의 효과(학습 없음) |
| R2 | A∪B | 최악 | 유사일 검색이 들어간 강건판(H2 = F23 R2) |
| W2 | A∪B | 기대 | 유사일 검색이 들어간 처방형 분석판(H1′) |
| (W1) | A | 기대 | **보고 전용**, 선택 대상 아님 — W2의 ML 증분 귀속용 |

## 4. 평가

- 대상 월 2(보고만)·4·5·7·8월(복제일 제외, `f11b_twolayer.dedup_days`), 3·6월은 복제 포함 민감도 행. s ∈ {0.10, 0.1295(s_kr = `f18_breakeven.s_kr()`), 0.337}. 8월 행은 "선택 오염(F11 선택 월)" 표시. 메모리는 2021-08-31까지만.
- 지표: 실현 월 최대, C0 대비, 사후 최적(P3b)과의 격차 감소, **계획이 만든 피크 일수**(실현 일 최대 > 무계획 일 최대 + 1kW인 날 수), 시나리오 수 평균, C0 대체 일수.

## 5. 선택·게이트 (F21 문면 그대로 + 단조 조건)

- **선택 규칙**: 4·5·7·8월 × 3 s = 12칸에서 칸마다 실현 월 최대 순위(동률 평균 순위), 평균 순위 최소 후보. 평균 순위 동률이면 C0 → R1 → W2 → R2 순으로 앞선 것. 2월은 보고만.
- **게이트**:
  - 통과 = 선택 ≠ C0 ∧ s_kr에서 4·5·7·8월 평균 월 최대 ≤ C0 평균 − 1.0kW ∧ s_kr에서 어느 달도 선택 > C0 + 1.0kW 아님 ∧ 12칸 중 선택 > C0(0.005kW 초과)인 칸 ≤ 3 ∧ **단조 조건**
  - 단조 조건: 한국 단조공장 2곳 × 4~9월 = 12공장-월(s = s_kr, cap = 20/204 × 직전 달 최대, `f19_kr_blind`와 같은 설정)에서 **현행보다 월 최대를 높인 공장-월 수가 C0 운전표보다 많지 않을 것**. 단조 자료엔 생산 계획이 없어 kNN을 만들 수 없으므로, 선택 후보의 **같은 위험 척도·A만 쓴 판**(R2·R1 → R1, W2 → W1)으로 잰다. 이 대체는 실행 전 확정이며 보고서에 그대로 적는다.
  - 부분 = 선택 ≠ C0이나 위 조건 중 하나 이상 미달 → 운영 C0 유지
  - 실패 = 선택 = C0
- **ML 증분(통과했을 때만)**: 선택이 R2면 s_kr 4개월 평균에서 R2 ≤ R1 − 0.5kW, W2면 W2 ≤ W1 − 0.5kW일 때 "유사일 검색이 운영에 기여했다"고 쓴다. 아니면 "이득은 시나리오 최적화에서 왔고 유사일 추가의 증분은 확인되지 않았다". 선택이 R1이면 학습 요소 없음.
